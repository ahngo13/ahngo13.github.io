안녕하세요! 오늘 여러분께 새로운 앱 소식을 전해드립니다.

## 우쿨렐레 코드 도우미가 출시됐어요

**우쿨렐레 코드 도우미**는 4현 GCEA 우쿨렐레의 자주 쓰이는 코드 35종을 다이어그램·운지법·실제 사운드로 한 번에 보여주는 학습 앱입니다. 인터넷 연결 없이 모든 기능이 동작하고, 광고 외에는 추가 결제도 없어서 누구나 편하게 사용할 수 있어요.

## 왜 이 앱을 만들었나요?

우쿨렐레는 배우기 쉬운 악기지만, 코드를 제대로 배우려면 여러 자료를 찾아봐야 하는 번거로움이 있었어요. 특히 입문자들은 "이 모양은 뭐고, 손가락은 어디에 놓지?" 하면서 헷갈리곤 합니다. 그래서 한 앱 안에서 **시각적 다이어그램, 정확한 운지 정보, 그리고 실제 우쿨렐레 소리**를 모두 확인할 수 있는 앱을 만들게 됐어요.

## 핵심 기능

### 📚 35개 코드 한눈에

메이저, 마이너, 도미넌트 7th, 메이저 7th, 마이너 7th, Sus 코드까지—자주 쓰이는 코드 35종을 모두 담았습니다. 각 코드마다 운지 위치, 손가락 번호, 바레 표시가 명확하게 표시되어 있어요.

### 🔊 실제 우쿨렐레 사운드

Karplus-Strong 합성 알고리즘을 사용해 GCEA(Reentrant) 튜닝의 4현을 시뮬레이션합니다. 녹음 파일이 아니라 실시간으로 생성되기 때문에 모든 코드를 반복 청취할 수 있어요.

### 🎮 재미있게 배우는 3가지 퀴즈 모드

- **다이어그램 → 코드명**: 손가락 위치 그림을 보고 코드 이름 맞히기
- **사운드 → 코드명**: 소리를 듣고 코드 이름 맞히기  
- **코드명 → 다이어그램**: 코드 이름을 보고 운지도 선택하기

### 📊 학습 진도 추적

누적 세션 수, 정답률, 카테고리별 정확도를 확인할 수 있고, 최근 점수 추이 그래프로 내 성장을 시각적으로 볼 수 있습니다. 통계는 JSON 파일로 백업하고 복원할 수도 있어요.

### 🔍 편리한 기능들

- **검색 + 필터**: 코드명으로 빠르게 찾을 수 있고, 카테고리별로 걸러볼 수 있어요
- **즐겨찾기**: 자주 연습하는 코드를 따로 모아두세요
- **다크/라이트 모드**: 시간대나 환경에 맞춰 자동으로 전환됩니다
- **한국어·영어 지원**: 원하는 언어로 학습하세요
- **100% 오프라인**: 인터넷 없이도 완벽하게 동작합니다

## 이렇게 활용해보세요

**우쿨렐레 입문자라면** 코드 퀴즈로 기본 35개를 차근차근 익혀보세요. 다이어그램을 보며 손가락 위치를 외우고, 사운드를 듣다 보면 어느샌가 코드가 들리게 돼요.

**이미 연주하는 분들이라면** 검색 기능으로 곡에 필요한 코드를 빠르게 찾아보거나, 좀 더 정확한 운지법을 확인하는 데 유용하게 쓸 수 있어요.

**자기주도 학습을 좋아하는 분들**은 매일 조금씩 퀴즈를 풀면서 학습 통계로 진도를 확인하는 재미를 느껴보세요.
