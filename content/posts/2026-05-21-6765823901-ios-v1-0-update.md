## 안녕하세요, 기타 코드 도우미입니다!

오늘 기쁜 마음으로 인사드립니다. **기타 코드 도우미**가 드디어 App Store에 공식 출시되었습니다! 기타를 배우고 계신 분들, 특히 복잡한 설정 없이 간단하게 코드를 찾아보고 싶으셨던 분들을 위해 정성스럽게 준비했습니다.

## 기타 코드 도우미는 어떤 앱인가요?

**기타 코드 도우미**는 통기타와 일렉기타 입문자, 취미 연주자를 위한 가장 단순한 코드 사전입니다. 보고 싶은 코드를 골라 다이어그램, 사운드, 연주 팁을 한 번에 확인할 수 있도록 만들었습니다.

특히 다음과 같은 상황에서 유용합니다:

- 악보나 책의 코드 운지법이 헷갈릴 때
- 카포나 변경 코드를 빠르게 찾아야 할 때
- 새로운 곡을 연습하기 전에 코드 진행을 미리 익히고 싶을 때
- 코드를 게임처럼 재미있게 배우고 싶을 때

## 주요 기능을 소개합니다

**🎨 컬러풀한 코드 다이어그램**

메이저, 마이너, 7th, 메이저 7th, 마이너 7th, Sus 등 핵심 카테고리별로 깔끔하게 정리되어 있습니다. 각 코드의 운지법, 베이스 프렛, 바레 위치까지 한눈에 파악할 수 있습니다.

**🔊 실감나는 사운드 재생**

Karplus-Strong 합성 사운드 기술로 기타 줄을 튕긴 듯한 자연스러운 코드 음을 들을 수 있습니다. 외부 오디오 파일을 따로 다운로드할 필요가 없어 가볍고 빠르게 동작합니다.

**⭐ 즐겨찾기 기능**

자주 쓰는 코드를 저장해두고 별도 탭에서 모아 볼 수 있습니다. 연습 중인 곡의 코드 진행을 빠르게 확인할 때 특히 유용합니다.

**📹 유튜브 연주 영상 연동**

코드 상세 화면에서 바로 관련 연주 영상을 검색하고 시청할 수 있습니다. 책으로만 보던 코드를 실제 어떻게 잡고 치는지 영상으로 확인하세요.

**🎮 코드 학습 퀴즈**

3가지 모드로 코드를 재미있게 익혀보세요:
- 다이어그램을 보고 코드명 맞히기
- 사운드를 듣고 코드명 맞히기  
- 코드명을 보고 다이어그램 고르기

매 세션 10문제로 짧은 시간에 집중적으로 학습할 수 있습니다.

**📊 학습 통계**

모드별 정답률과 베스트 점수, 최근 점수 추이 그래프, 카테고리별(메이저·마이너·7th 등) 정답률을 시각적으로 확인할 수 있습니다. 약한 코드 카테고리를 쉽게 발견하고 보강하세요.

**🌍 다국어 지원**

한국어와 영어를 설정에서 자유롭게 전환할 수 있습니다.
