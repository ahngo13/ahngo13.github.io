## 반갑습니다, iOS 사용자분들!

공평엔빵이 드디어 iOS 앱으로 여러분을 찾아갔습니다. 그동안 안드로이드에서만 만나볼 수 있었던 더치페이 정산 계산기가 이제 아이폰과 아이패드에서도 언제 어디서나 부담 없이 사용할 수 있게 됐어요.

출시 직후 첫 업데이트인 1.0.6에서는 실제 사용자분들의 피드백을 반영해 몇 가지 개선사항을 담았습니다. 더 나은 경험을 위해 어떤 것들이 바뀌었는지 함께 살펴보세요.

## 이번 업데이트에서 달라진 점

### 1. 더 깔끔해진 정산 탭 화면

정산 탭 첫 화면에 있던 뒤로가기 버튼을 제거했어요. 더 이상 불필요한 버튼으로 공간이 낭비되지 않으니 화면이 한결 깔끔해졌습니다.

### 2. 공유 방식 선택 시 설명 추가

간단형, 상세형, 개인형 중 어느 형식을 고를지 결정할 때 각각이 어떤 정보를 담는지 바로 확인할 수 있도록 했어요. 이제 "어떤 형식으로 공유하지?"라고 고민하지 않아도 원하는 형식을 명확하게 선택할 수 있습니다.

### 3. 화면 제목 표시 통일

앱 전체에서 각 화면의 제목 표시 방식을 통일해 더욱 일관된 UI 경험을 제공합니다.

### 4. 백업 안내 문구 개선

백업이 "자동으로" 이루어진다고 오해할 수 있던 문구를 명확하게 수정했습니다. 공평엔빵은 모든 데이터가 사용자 기기에만 저장되며, 필요할 때 직접 백업하고 불러올 수 있어요.

## 공유 기능을 더 잘 활용하기

이번 업데이트로 강화된 공유 방식 설명을 활용하면 상황에 딱 맞게 정산 결과를 전달할 수 있습니다.

- **간단형**: 누가 누구에게 얼마를 보내면 되는지 필수 정보만 포함 → 단톡방에서 빠르게 확인할 때
- **상세형**: 각 항목의 상세 내역까지 담음 → 나중에 다시 확인하거나 기록하고 싶을 때
- **개인형**: 특정 개인의 입출금 내역만 표시 → "내가 얼마 내면 되는데?"라는 질문에 즉시 답할 때

정산 결과를 텍스트로 복사해 단톡에 붙이거나, 이미지로 저장해 SNS 공유도 가능하니 모임의 상황에 맞춰 자유롭게 활용해 보세요.

## 앞으로도 함께하겠습니다

회식 1차, 2차, 3차 참석자가 다를 때, 술 안 마시는 멤버가 있을 때, 여행 중 각자 낸 경비를 정산해야 할 때 — 공평엔빵은 항상 준비돼 있습니다. 

회원가입 없이, 로그인 없이, 서버에 데이터를 보내지 않으면서도 복잡한 정산을 몇 초 만에 끝내주는 것이 공평엔빵의 철학입니다. iOS 사용자분들도 이 경험을 느껴보세요.

더 좋은 앱이 되기 위해 계속 개선하고 있습니다. 사용하면서 불편한 점이나 추가되면 좋을 기능이 있다면 언제든지 피드백해 주세요. 여러분의 의견이 공평엔빵을 더 똑똑하고 편하게 만듭니다.
