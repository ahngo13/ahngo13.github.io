안녕하세요! 개발자 안시우입니다.

오늘 소개할 앱은 **What It Calls - API Checker**입니다. 깃허브에서 발견한 흥미로운 AI 도구를 받았는데, "무료"라는 말이 무색하게 API 키를 요구받은 경험이 있으신가요? 혹은 회사에 새로운 오픈소스 도구를 도입하려는데 정말 로컬에서만 돌아가는지 의심스러우신가요? 이 앱은 그런 의문에 답하기 위해 만들었습니다.

## 코드로 사실을 말해주는 앱

What It Calls는 깃허브 저장소의 코드를 읽어 그 도구가 어떤 외부 API를 부르는지 보여줍니다. 핵심은 **평가나 점수를 매기지 않는다**는 것입니다. 대신 근거가 되는 코드 줄과 요금 출처를 그대로 제시합니다. "무료라고 했는데 실제로는?"이라는 질문에 코드가 대답하는 셈입니다.

## 어떻게 사용하나요?

사용법은 매우 간단합니다. GitHub 주소를 앱에 붙여 넣고 "점검"을 누르면 끝입니다. 이미 점검된 저장소라면 바로 결과가 열리고, 처음 보는 저장소면 그 자리에서 점검이 시작됩니다.

결과는 네 가지 상태로 제시됩니다. **외부 API 사용** (핵심 기능이 외부 API를 부름), **외부 API 사용·로컬 대안 있음** (외부 API를 쓰지만 로컬 실행 경로도 있음), **외부 API 발견 안 됨** (점검 범위에서 외부 호출을 찾지 못함), **확인 필요** (근거가 모자라 단정하지 않음)로 나뉩니다.

한 번의 점검 결과에는 "키 없이 되는 범위", "부르는 외부 API의 회사와 주소", "외부로 나가는 데이터", "README 설명과 코드의 차이", "커밋에 고정된 근거 코드 줄 링크" 등이 담겨 있습니다. 투명함을 최우선으로 했습니다.

## 이런 상황에서 유용합니다

"무료" AI 도구를 받았는데 예상과 달리 API 키를 요구받은 분들에게 좋습니다. 사내에서 오픈소스 도구를 도입하기 전에 데이터가 어디로 나가는지 확인해야 하는 분들에게도 도움이 될 거예요. 또한 정말로 로컬에서만 돌릴 수 있는 도구를 찾는 분들이라면 더욱 유용할 것입니다.

앱은 회원가입 없이 바로 쓸 수 있으며, 한국어와 영어를 지원합니다. 최근 점검한 저장소, 용도별 저장소(코딩 에이전트·이미지·영상·음성·문서·리서치 등), 자주 등장하는 외부 API 목록도 둘러볼 수 있습니다.

## 마치며

What It Calls는 GitHub과 제휴하지 않은 독립 서비스입니다. 점검 결과는 공개된 코드를 자동으로 읽어 만든 사실 정보이며, 특정 저장소나 개발자를 평가하지 않습니다.

혹시 결과가 틀렸다면 정정을 요청할 수 있습니다. 확인 후 결과를 고쳐드릴 테니까요.
