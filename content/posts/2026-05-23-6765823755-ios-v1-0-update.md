안녕하세요! 우쿨렐레 코드 도우미 개발팀입니다.

오늘 여러분께 기쁜 소식을 전해드립니다. **우쿨렐레 코드 도우미가 App Store에 정식 출시**되었습니다! 우쿨렐레를 배우고 싶던 많은 분들의 요청을 받아, 드디어 여러분의 아이폰과 아이패드에서 만나볼 수 있게 되었어요.

## 우쿨렐레 코드 도우미는 어떤 앱인가요?

이 앱은 4현 GCEA 우쿨렐레의 자주 쓰이는 35가지 코드를 **다이어그램, 운지법, 실제 사운드**로 한 번에 보여줍니다. 복잡한 설정 없이 App Store에서 다운로드하면 바로 학습을 시작할 수 있어요.

## 핵심 기능들

**1. 35가지 코드 완벽 구성**
메이저, 마이너, 도미넌트 7th, 메이저 7th, 마이너 7th, Sus 코드까지 우쿨렐레 입문자부터 중급자까지 필요한 모든 코드를 담았습니다.

**2. 진짜 우쿨렐레 사운드**
Karplus-Strong 합성 알고리즘으로 실제 악기 소리를 시뮬레이션합니다. 녹음 파일이 아니므로 모든 코드를 실시간으로 재생하고 반복해서 들을 수 있어요.

**3. 3가지 모드 코드 퀴즈**
- 다이어그램을 보고 코드명 맞히기
- 사운드를 듣고 코드명 맞히기
- 코드명을 보고 다이어그램 선택하기

재미있게 학습하면서 자연스럽게 코드를 익힐 수 있습니다.

**4. 학습 통계로 나의 진행도 확인**
누적 세션 수, 정답률, 카테고리별 정확도, 최근 점수 추이 그래프로 학습 현황을 한눈에 파악하세요. 통계는 JSON 파일로 백업·복원도 가능합니다.

## 더 편리한 기능들

- **코드 검색 + 카테고리 필터**: 원하는 코드를 빠르게 찾아보세요
- **즐겨찾기**: 자주 연습하는 코드를 저장해두세요
- **다크 모드 지원**: 밤에도 편하게 사용할 수 있어요
- **한국어·영어 지원**: 언어에 맞춰 사용하세요
- **완전 오프라인 동작**: 인터넷 연결 없이 100% 작동합니다
- **회원가입 불필요**: 로그인 없이 바로 시작할 수 있어요
- **광고 외 추가 결제 없음**: 깨끗한 학습 환경을 제공합니다

## 누가 이 앱을 사용하면 좋을까요?

우쿨렐레 입문자, 독학하고 계신 분, 그리고 레슨 중간에 빠르게 코드를 확인하고 싶은 모든 우쿨렐레 연주자들에게 추천합니다. 특히 통근 시간이나 자투리 시간에 가볍게 코드를 익히고 싶으신 분들이라면 완벽하실 거예요.
