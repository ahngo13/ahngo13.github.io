## 안녕, 1.0.6 업데이트 소식이야

방찾기 기록 쓰면서 불편했던 부분들 이번에 꽤 많이 손봤어. 특히 금액 표기랑 검색 관련해서 신경 쓰이던 버그들 위주로 정리했어.

## 이번에 바뀐 것

- **큰 금액 표기 수정**: 1억 원 넘는 금액을 「2억 3,000만원」처럼 억 단위로 끊어서 보여줘. 월세가 1억 원 이상일 때 「월 1억만원」으로 이상하게 나오던 문제도 고쳤어.
- **검색/필터 결과 없을 때**: 「조건에 맞는 방이 없어요」 문구랑 필터 초기화 버튼이 뜨고, 다른 탭 다녀와도 검색어가 검색창에 그대로 남아있어.
- **전환율 입력칸**: 「2.52.5」처럼 잘못된 숫자 들어가던 버그 막았어.
- **부동산 카드 버튼**: 전화·문자 버튼 눌러도 반응 없던 문제 고쳤고, 지도 버튼 누르면 카카오맵·네이버 지도로 바로 열려.
- **등록 화면 저장 버튼**: 매물·부동산 등록할 때 아래 저장 버튼이 입력란 가리던 문제 해결.
- **화면 가림 문제**: 설정 화면이랑 주소 검색 결과 아래쪽 가려지던 것, 전체 평가 섹션이 설정 무시하고 항상 펼쳐지던 것도 정리했어.

## 활용 팁

방 여러 개 보고 다니다 보면 전세가 억 단위로 넘어가는 경우 많잖아. 이제 숫자 읽기 훨씬 편해졌으니 목록을 월 환산 실부담순으로 정렬해서 비교할 때 금액 헷갈릴 일 줄었을 거야. 그리고 전환율은 지역 시세 보면서 직접 조정하는 값인데, 입력칸 버그 고쳤으니 숫자 입력할 때 한 번 더 확인 안 해도 돼. 부동산 연락처 저장해놓고 카드에서 바로 전화·문자·지도 켜는 흐름도 다시 써봐.
