안녕하세요, 링크몰랑입니다!

저희 앱을 사랑해주시는 iOS 사용자 여러분을 위해 새로운 업데이트를 준비했습니다. 버전 1.0.3에서는 더 편리한 언어 설정과 실용적인 기능들을 추가했으니 한번 확인해보세요.

## 이번 업데이트의 주요 변경사항

### 1. 앱 언어를 직접 선택할 수 있어요

기존에는 시스템 설정을 따라가던 언어 선택이 이제 앱 내에서 직접 결정할 수 있습니다. **시스템 설정**, **한국어**, **영어** 중에서 원하는 언어를 고르면 되는데요, 이제 더 이상 기기 설정을 바꿀 필요 없이 링크몰랑만 영어로 사용하는 것도 가능해졌어요!

해외 팔로워들과 협업할 때 앱은 한국어로, 프로필 페이지는 영어로 운영하고 싶다면 설정에서 언어를 바꿔보세요.

### 2. 웹에서 만든 이미지를 기기에 바로 저장

웹에서 프로필 페이지를 꾸미다가 마음에 드는 이미지가 생겼을 때, 이제 바로 아이폰이나 아이패드에 저장할 수 있습니다. 스크린샷을 찍거나 복잡한 과정을 거칠 필요 없이, 한 번의 탭으로 완료되니 훨씬 간편해졌어요.

### 3. 공유 기능 및 안정성 개선

친구에게 내 프로필을 공유할 때 더 부드럽고 빠르게 동작하도록 최적화했습니다. 또한 앱 전반의 안정성을 개선해서 더 쾌적한 경험을 제공하려고 노력했어요.

## 새 기능을 어떻게 활용할까요?

**다언어 운영을 꿈꾸는 크리에이터라면**: 설정(Profile Settings)에서 원하는 언어를 선택하고, 프로필 페이지 설정에서 다시 한 번 언어를 지정해보세요. 방문자가 보는 페이지는 당신이 설정한 언어로 표시됩니다.

**프로필 페이지를 자주 수정한다면**: 웹에서 테마를 시험해본 후 마음에 드는 디자인을 스크린샷 대신 이미지로 저장해두면 나중에 참고하기 좋습니다.
